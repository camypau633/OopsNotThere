# ОЙ, НЕ ТУДА!

Небольшая бесплатная мобильная головоломка: игрок проходит короткие уровни, а игра неожиданно меняет правила.

## Технологии
- HTML5, CSS, JavaScript
- Phaser 3 (подключается через CDN)
- PWA: manifest и service worker
- GitHub Actions для базовых проверок

## Запуск
Откройте сайт, опубликованный через HTTPS. Для локальной проверки нужен простой HTTP-сервер; запуск через `file://` не поддерживает PWA.

## Текущий этап
Стартовая структура проекта. Игровая логика и автоматические проверки добавляются поэтапно.

## Цель
Любительский проект ради интереса. Нет аккаунтов, серверной части, рекламы или платных функций.
